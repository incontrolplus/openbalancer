По какви параметри се балансира трафикът

ПО AI МОДЕЛ & КОНТЕКСТ

vLLM & Token Context Routing

Анализира дължината на промпта и наличната GPU VRAM памет, пренасочвайки заявката към нода с най-оптимален KV кеш без латентност.

ПО ТОКЕН БЮДЖЕТ & RATE LIMIT

Token-Bucket Rate Limiting

Стриктно следене на консумацията на токени в секунда per-client/per-tenant, елиминирайки претоварването на AI инференс клаудите.

ПО LATENCY SLA & HEALTH PROBE

Active Health Probing < 0.24ms

Непрекъснато асинхронно тестване на здравето на сокетите през фонови таскове с нулева пауза при failover превключване.

ПО CUDA OOM FAILOVER

Автоматичен GPU Fallback

При възникване на HTTP 500/503 или GPU Out-Of-Memory грешка, заявката мигновено се повтаря към резервен клъстерен нод.

Kernel & Event Loop Architecture

Engineered for High-Concurrency Protocols

Built from the ground up on non-blocking asynchronous sockets with zero external dependencies in the hot path.

Protocol Agnostic Routing

Full support for HTTP/1.1, HTTP/2 multiplexing, long-lived WebSockets, Server-Sent Events (SSE), and gRPC streaming.

Active Circuit Breaking

Detects consecutive 5xx errors or socket timeouts in milliseconds, instantly tripping degraded upstream backends out of the pool.

Multi-Algorithm Balancing

Select between Weighted Round-Robin, Smooth Least Connections, and Consistent IP Hash Rings for session sticky routing.
